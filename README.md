# Turbin3 Prerequisite Project

This is my Vault program project for the Turbin3 Prerequisite Assignment. I built it using Rust and Anchor on Solana.

## Features

* Initialize a vault
* Deposit SOL
* Withdraw SOL
* Close the vault
* Register my GitHub username using CPI
